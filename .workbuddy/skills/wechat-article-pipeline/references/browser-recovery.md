# 浏览器恢复与回退

## 恢复原则

浏览器自动化断连后通过 WorkBuddy 浏览器自动化（agent-browser）重新获取会话并列出标签页，使用已记录的 `draft_id` 或 `draft_url` 恢复原草稿；不要按标题另建草稿。每次操作前读取当前可见文本、角色和 DOM，坐标只作临时回退。

## 富文本写入回退

按以下顺序尝试，并在状态中记录实际路径：

1. 当前可见正文 `contenteditable` 的 DOM 写入，并触发 `beforeinput`、`input`、`change`。
2. 复制已渲染预览 DOM 的富文本粘贴（优先 CF_HTML/native clipboard）。
3. 纯文本粘贴，仅在前两者失败时使用，并将排版状态标记为 degraded，保存前重新检查块级结构和图片。

不要把 HTML 源字符串直接当作普通文本粘贴，也不要用编辑器单次出现的字符数代替结构验证。

## 封面上传与持久化

封面替换必须使用新文件名。先通过页面上传控件触发 file chooser，确认图片库出现该文件名；再选择该条目、完成裁切/确认并回读封面预览的微信 CDN URL。保存后重新加载编辑器，并回到草稿列表检查列表卡片背景 URL 非空且对应本次新资产。只有这些条件全部满足，封面才是 `persisted`。

## 保存安全边界

只点击“保存为草稿”或等价动作。遇到扫码、验证码、风控、账号不一致或上传权限失败时停止，保留本地产物和 blocker；不点击发表、群发、定时发表或推广。
