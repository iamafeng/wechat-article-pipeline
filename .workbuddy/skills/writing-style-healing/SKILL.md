# 治愈系写作风格

一种轻声说话的中文风格。目标读者**不是为了获取信息来的，是为了被理解一次**。

它不解决问题，也不给方法论。它做的事是：把一个人人都经历过的、说不出口的小东西，准确地写出来，
让读者觉得"原来不止我这样"。

## 一、语言底线

这几条是硬约束，违反任意一条即需返工。

**温度藏在克制里，不在台词里。**
一个不说话的小动作，胜过一段暖心独白。
写"她把多打的那份粥推给隔壁桌的老人，没说话，低头继续扒自己的饭"，
不写"善良总会被世界温柔以待"。
让读者自己捂热那一下，不要替读者感动。

**先冷后暖，暖才有重量。**
纯甜是假的。先有现实的累、委屈、孤独，再给一点点暖，对比之下才砸得到心里。
没有冷的部分，暖就变成了糖水。

**余味等于不说满。**
结尾留一个没说出口的善意，或一个开放的小希望，让读者自己补完。
不要总结主题，不要点明"这件事告诉我们"。

**反鸡汤：把道理翻译成具体的人做的具体的事。**

- 反例："生活总会善待努力的人。"
- 正例："他每天收摊前把剩下的两个包子留给巷口的流浪猫，坚持了三年，从未跟人提过。"

**禁用的表达方式：**

- 煽情词堆砌（`泪目`、`破防`、`人间值得`、`治愈`、`温暖`，尤其禁止把"治愈"这个词写进正文）
- 金句体（`你要相信……`、`愿我们都能……`、`生活会给你答案`）
- 说教句（`我们应该学会……`、`其实只要……就能……`）
- 空洞形容词（`治愈的`、`温暖的`、`美好的`、`柔软的`）→ 换成可以看见、听见、摸到的东西
- 强行升华（`这一刻我明白了人生的意义`）
- 总结性套话（`综上所述`、`总而言之`、`生活就是这样`）
- 破折号插入语 → 改成独立短句
- 三段式排比（`不是……不是……而是……`）

**语气：**
轻声、平等、不俯视。可以写"我"，但不要用"你"来指指点点。
不用感叹号制造情绪。感叹号全篇最多一个，最好零个。
不喊口号，不替读者下结论。

## 二、结构

文章结构，不是小说的起承转合。不要编人物、编对话、编剧情。

**开头：从一个具体场景切入。**
一个画面、一个动作、一句没头没尾的话。
前三段内读者要"看见"某个东西，而不是被告知"这篇文章要讲什么"。
反面教材：从时代背景、行业趋势、人生感悟慢慢说起。

**中段：展开真实的困境，但不夸大。**
把那个"说不出口的小东西"写具体：它什么时候出现，长什么样，让人怎么难受。
困境要轻，不能狗血。写"删了又写的那条消息"，不写"人生的至暗时刻"。

**转折：一个细节，不是一次开挂。**
现实逻辑里的转折 —— 一个陌生人的一句话、一个偶然看到的画面、一次没做成的尝试。
不要贵人相助，不要突然想通。

**认知位移：轻微，不是顿悟。**
人物（或作者自己）对这件事的看法发生了一点点变化。
"我还是会难过，但好像没那么急了"，这就够了。

**结尾：克制收束，留余味。**
回到开头的那个画面，或者停在某个未完成的小动作上。
不要总结，不要升华，不要呼吁。

**小标题：**
长文（>1800 字）用小标题做节奏锚点，每 350 到 550 字一个 —— 比中性风格更密一些，
因为治愈系需要更多的呼吸停顿。
小标题偏短，可以是短语或一个具体物件，不必是完整陈述句，但要能独立读通。

**节奏：**
短段落为主。允许一两句话单独成段，那是留给读者喘气的地方。
段落长度要有变化，不要每段都一样。

## 三、事实与诚实

- 不编造人物、对话、心理活动、剧情。治愈系最容易犯的错就是"编一个感人的故事"。
- 不编造作者自己的经历、情绪、对话。素材里没有就写"这部分需要你补充个人经历"，
  **不要用通用场景冒充亲历** —— 治愈系一旦被发现是虚构的，读者的信任会彻底崩塌。
- 引用外部事实时标注来源，来源不明就写"据公开资料"，不确定就写"待核实"。
- 数字、日期、版本、人名，动笔前后各核一遍。
- 真实素材里的细节（一个动作、一句原话、一个时间）优先使用，它们是全篇可信度的支点。

## 四、消费流水线的交接块

被 wechat-article-pipeline 调用时，你会收到一段交接块，包含：选题、目标读者、核心判断、
可用素材、禁止编造项、来源归属、语气要求。

处理方式：

1. 以交接块里的**核心判断**为文章主干，不要另起一个更"安全"的观点。
2. **禁止编造项**里列出的空白，绝不填充。治愈系尤其不能靠虚构来"补情绪"。
3. 素材里给的真实细节优先使用，它们是文章可信度的主要来源。
4. 交接块指定的禁用/必用语气，优先级高于本文件的默认规则。
5. 如果选题本身是硬核技术或数据驱动，主动提示"这个题材用 writing-style-plain 更合适"，
   不要为了治愈而治愈。

## 五、质检清单

成稿后逐项自查，任一项不通过就修改后重查。

**L1 硬性规则**
- [ ] 无煽情词、金句体、说教句、空洞形容词
- [ ] 正文中不出现"治愈"这个词
- [ ] 无破折号插入语、三段排比、总结套话
- [ ] 感叹号全篇不超过 1 个
- [ ] 小标题能独立读通，长文有节奏锚点

**L2 情绪**
- [ ] 情绪是"演出来"的，不是"喊出来"的（找出至少 2 处承载情绪的具体动作或细节）
- [ ] 有"冷"的部分在前，暖才有重量
- [ ] 结尾没有总结主题、没有升华、没有呼吁
- [ ] 全篇没有一处替读者感动

**L3 诚实**
- [ ] 无虚构的人物、对话、心理活动、剧情
- [ ] 无虚构的作者亲历
- [ ] 外部事实有来源标注
- [ ] 禁止编造项没有被填充

**L4 像人写的**
- [ ] 至少 2 处感官细节（气味、声音、触感、光线、温度）
- [ ] 通读一遍，没有"这段换成谁都能写"的段落
- [ ] 节奏有快有慢，有一两句单独成段的呼吸处
- [ ] 删掉第一句后读一遍，确认没有"AI 开场白"感
- [ ] 读完之后，心里是不是有一点点软？没有就重写开头和结尾

## 六、不做的事

- 不模仿任何特定作者或账号的口吻（那是 khazix-writer 之类人格化技能的职责）
- 不编故事。这是写作风格，不是小说生成器
- 不为治愈而治愈：硬核、数据驱动、争议性强、需要明确结论的选题，不要用这个风格
- 不用 emoji 装饰正文
- 不在正文中解释"我是 AI"或讨论写作过程，除非文章主题就是它

## 七、配图建议

这个风格默认搭配 **hand-drawn-watercolor（手绘水彩）** 配图风格：
暖色、可见笔触、柔化边缘、留白多、无文字。
完整提示词骨架见流水线的 `references/illustration-styles.md`。
封面尤其要避免"抽象装饰"，要画得出文章里那个具体的场景或物件。
