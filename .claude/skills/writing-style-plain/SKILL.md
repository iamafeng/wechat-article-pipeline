# 干净直白体写作风格

一种不带人格面具的中文书面风格。目标读者是**想快速搞懂一件事的人**，不是来感受作者性格的。

它和人格化风格的区别：不追求"像某个具体的人"，追求"把事情讲清楚且不让人出戏"。

## 一、语言底线

这几条是硬约束，违反任意一条即需返工。

**具体优先于抽象。**
写"我试了三次，前两次都卡在扫码登录"而不是"过程中遇到了一些困难"。
写"响应时间从 800ms 降到 120ms"而不是"性能显著提升"。
没有数字时，给可验证的事实，不给形容词。

**一句话只装一个意思。**
长句拆成短句。超过 40 字的句子检查一遍，能断就断。
段落控制在 3 到 5 句，超过就分段。

**禁用的表达方式：**

- 冒号式标题（`关键问题：我们该如何应对`）→ 改成陈述句或疑问句
- 破折号插入语（正文中用 `——` 打断句子）→ 改成独立短句
- 三段式排比（`不是……不是……而是……`）→ 直接说结论
- 空洞的层递（`不仅仅……更是……`）→ 删掉前半句
- 总结性套话（`综上所述`、`总而言之`、`值得一提的是`、`在这个……的时代`）
- 虚假范围（`所有人都知道`、`众所周知`）→ 给出处，或删掉
- 空洞形容词堆砌（`极大地`、`深刻地`、`全面地`）→ 删掉，或换成数据

**语气：**
平实、直接、不煽情。可以有判断，但判断后面必须跟理由。
不用感叹号制造情绪，不用反问句凑气势。

## 二、结构

**开头：先给结论或冲突，不要铺垫。**
前三段内读者要拿到"这篇文章要说什么"和"为什么值得读"。
反面教材：从行业背景、时代趋势、个人感悟慢慢说起。

**中段：按读者的疑问顺序展开，不是按你的思考顺序。**
每解决一个疑问再抛下一个。章节之间用一句过渡说明"接下来回答什么"。

**结尾：回到读者，不要升华。**
给一句"你现在可以做什么"，或者一个仍未解决的诚实说明。
不要写"让我们拭目以待"这类无信息量的收尾。

**小标题：**
长文（>2000 字）用小标题做节奏锚点，每 400 到 600 字一个。
小标题是陈述句，能独立读通，不依赖上下文。

## 三、事实与诚实

- 不编造数据、案例、对话、心理活动、个人经历。
- 引用外部事实时标注来源，来源不明就写"据公开资料"，不确定就写"待核实"。
- 需要第一手经历但素材里没有时，写"这部分需要你补充个人经历"，**不要用通用场景冒充亲历**。
- 数字、版本、日期、人名，动笔前后各核一遍。

## 四、消费流水线的交接块

被 wechat-article-pipeline 调用时，你会收到一段交接块，包含：选题、目标读者、核心判断、可用素材、禁止编造项、来源归属、语气要求。

处理方式：

1. 以交接块里的**核心判断**为文章主干，不要另起一个更"安全"的观点。
2. **禁止编造项**里列出的空白，绝不填充，按上文"诚实"规则处理。
3. 素材里给的真实细节（具体工具名、报错信息、耗时、数字）优先使用，它们是文章可信度的主要来源。
4. 交接块指定的禁用/必用语气，优先级高于本文件的默认规则。

## 五、质检清单

成稿后逐项自查，任一项不通过就修改后重查。

**L1 硬性规则**
- [ ] 无冒号标题、破折号插入语、三段排比、总结套话、虚假范围
- [ ] 无空洞形容词堆砌
- [ ] 段落不超过 5 句，句子平均长度不失控
- [ ] 小标题是陈述句且能独立读通

**L2 内容**
- [ ] 开头三段内给出了结论或冲突
- [ ] 每个判断后面有理由或证据
- [ ] 所有数字、日期、版本、人名已核对
- [ ] 禁止编造项没有被填充

**L3 诚实**
- [ ] 无虚构的经历、对话、心理活动
- [ ] 外部事实有来源标注
- [ ] 不确定的地方明确标注，未含糊带过

**L4 像人写的**
- [ ] 通读一遍，没有"这段换成谁都能写"的段落
- [ ] 至少 3 处只有掌握素材的人才能写出的具体细节
- [ ] 节奏有快有慢，不是每段都一样长
- [ ] 删掉第一句后读一遍，确认没有"AI 开场白"感

## 六、不做的事

- 不模仿任何特定作者或账号的口吻（那是 khazix-writer 之类人格化技能的职责）
- 不为了"生动"而牺牲准确
- 不用 emoji 装饰正文
- 不在正文中解释"我是 AI"或讨论写作过程，除非文章主题就是它
